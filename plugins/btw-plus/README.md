# btw-plus

Claude Code 用のプラグインです。標準の `/btw` を拡張し、**ツールが使える**、**履歴を覚える**、**サイドウィンドウに答えが出る**、**画面で選択した文章を引用して質問できる**、**答えをメインの会話に戻せる**ようにします。質問と回答は、あなたが戻すまでメインの会話に入らないので、本筋のコンテキストを汚しません。

(English: a side-question window for Claude Code with tools, memory, quoting of selected text, and optional injection of answers back into the main conversation.)

## インストール

```
claude plugin marketplace add TIH-HIT/claude-plugins
claude plugin install btw-plus@tih-hit-plugins
```

セッション内なら `/plugin marketplace add TIH-HIT/claude-plugins` のあと `/plugin install btw-plus@tih-hit-plugins` です。デスクトップアプリでは、プロンプト横の「+」→ Plugins → Add marketplace に `TIH-HIT/claude-plugins` を入れて、Add plugin を押します。

## 使い方

- **ペインをクリックして、そのまま入力して Enter**(`/btw-pane` でペインを開く)。入力欄を別に押す必要はありません。
- または、プロンプトの先頭に `q:` / `btw:` / `？？`(全角)を付けて送る。例: `q: この関数のテストはどこ?`
  半角の `??` は、空のプロンプトで `?` を押すと標準のヘルプが開くため、既定では使いません。
- 質問ごとに、いまのセッションを複製したものが答えます。読み取り系のツールと Web 検索が使えます。編集系は常に禁止です。

### ペインの構成

- **上(固定)**: `記憶: ON/OFF` / `直近 N 件` / モデル・エフォートの選択ボタン列(クリックで直接選べる)(モデルは `fable` `opus` `sonnet` `haiku` の別名。別名は Claude Code が最新に解決するので、新モデルにも自動で追随) / `履歴を消す` / `メインに反映`。スクロールせずにいつでも押せます。
- **中**: 履歴。新しい質問が下に来ます。古い履歴や長い回答は、ホイールまたは `^` / `v` で見ます。
- **下(固定)**: 引用ボタンと入力欄。

### 選択した文章を引用する

1. 画面の文章をドラッグで選択する(選択しただけでは何も起きません)。
2. ペイン下の **`選択を引用`** を押す。「引用中」の枠に入ります。
3. 質問を送ると、その文章が付きます。引用は1回の質問で使い切りです。やめたいときは `外す`。

選択の取得は、デスクトップアプリとフルスクリーン表示のターミナルで動きます。Ctrl+ドラッグなど、修飾キーを使った操作はエンジンが渡さないため実現できません。

### 長い回答

回答は省略しません。ヘッダと入力欄は固定したまま、間の履歴だけをマウスホイールやスクロールキー、`^` `v` ボタンで行ごとにスクロールして読みます。新しく質問すると、いちばん下(最新)に戻ります。履歴の領域は、ペインの高さから計算します。

### 答えをメインの会話に戻す

- 各回答の **`メインへ`** で、その Q&A を1件、メインの会話に追加します(押すと `メイン済`)。ターンは始まらず、次にあなたが話すときにモデルが読めます。
- ヘッダの **`メインに反映`**、または `/btw-inject`(最新1件)/ `/btw-inject all`。
- 設定の「回答を自動でメインの会話に入れる」をオンにすると、回答のたびに自動で追加します(既定はオフ)。

### 表示する場所(横 / 入力欄の上)

- **ペイン(既定)**: フルスクリーン表示では画面の横、そうでなければ入力欄の上に出ます。横幅が狭いので、Markdown の表が崩れやすくなります。
- **バンド**: 入力欄のすぐ上に、メインの会話と同じ幅で出ます(ターミナルとデスクトップのみ。高さは画面の半分まで)。表を読むならこちらです。

ヘッダの `表示: 横` / `表示: 下` で切り替えるか、設定の「表示位置」(`pane` / `band`)で既定を決めます。バンドは `閉じる` で閉じ、次の質問でまた開きます。

### ペインの大きさ

ペインの境界をドラッグ(またはキー操作)して変えられます。変えた大きさが優先されます。開くときの希望サイズは、設定の「ペインの幅」「ペインの高さ」で指定できます。

### 記憶

直前までのサイド質問と回答(既定は直近5件)を、次の質問に引き継ぎます。

| 操作 | ペインのボタン | コマンド |
|---|---|---|
| 記憶の ON/OFF | 記憶: ON/OFF | `/btw-memory on` / `off` |
| 引き継ぐ件数 | 直近 N 件 | `/btw-memory 10` |
| このセッションの履歴を消す | 履歴を消す | `/btw-clear` |
| ピン留めも含めて全部消す | なし | `/btw-clear all` |

各回答の「ピン留め」を押すと、その回答はどのセッションでも常に引き継がれます。「回答をコピー」「削除」もあります。

## 設定

`/config` のプラグイン設定から変えられます。

| 項目 | 既定 | 内容 |
|---|---|---|
| 自動許可するツール | `Read,Grep,Glob,WebSearch,WebFetch` | 許可リストにないツールは拒否されます |
| モデル | (セッションの既定) | 例: `haiku` |
| エフォート | (セッションの既定) | `low` `medium` `high` `xhigh` `max`。サイド質問だけに効く |
| 質問の接頭辞 | `q:,btw:,？？` | カンマ区切り |
| タイムアウト(秒) | `270` | 最大 600 |
| ペインの幅 / 高さ | `0`(標準) | 開くときの希望サイズ |
| 操作ボタンと入力欄を固定する | オン | 表示が崩れるときはオフ |
| 回答を自動でメインの会話に入れる | オフ | |

## 注意

- 質問のたびに会話全体を読み込むので、長いセッションではトークンを使います。回答まで数十秒かかることがあります。
- 履歴は最大100件です。古い順に消えます(ピン留めを除く)。
- Windows(WSL)・macOS・Linux で動きます(OS 依存の処理はなく、`claude` コマンドが PATH にあれば足ります)。
- Claude Code の mod 機能(早期提供)を使っています。古いバージョンでは動かない場合があります。
